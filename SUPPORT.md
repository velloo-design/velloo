# Support

- **Questions, ideas, show-and-tell** → [GitHub Discussions](https://github.com/velloo-design/velloo/discussions)
- **Bugs and feature requests** → [open an issue](https://github.com/velloo-design/velloo/issues/new/choose)
- **Security issues** → see [SECURITY.md](./SECURITY.md); do not file a public issue

A quick search of existing issues and discussions before filing usually saves
everyone time.
