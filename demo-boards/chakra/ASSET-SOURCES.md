# Elsewhere image provenance

The six bundled travel photographs were generated for this repository on
2026-09-14 and imported into the design folder through Velloo MCP. They are
illustrative demo assets, contain no stock photography, and have no external
source or attribution requirement. Exact prompts are recorded in `assets.json`.

| Local asset | Purpose |
| --- | --- |
| elsewhere-kyoto.jpg | Kyoto hero and destination imagery |
| elsewhere-japan.jpg | Night-alley itinerary and journal imagery |
| elsewhere-bali.jpg | Bali destination card |
| elsewhere-alps.jpg | Alps destination card |
| elsewhere-room.jpg | Guest-room hero and journal imagery |
| elsewhere-forest.jpg | Forest journal and library imagery |

The `elsewhere-kyoto-map.svg` and inline compass SVG were authored specifically
for this sample. Route positions are illustrative.
