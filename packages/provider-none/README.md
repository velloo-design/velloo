# @velloo/provider-none

The bare-primitives provider. No component library, no portals, no
providers — just plain HTML elements wrapped to play nicely with the
canvas inspector and Tailwind-utility overrides.

## When to use

- You're prototyping a screen that doesn't fit shadcn's idioms (custom
  illustrations, brand mark, oddly-shaped hero).
- You haven't picked a UI library yet and want to mock the layout.
- You're learning Velloo and want the smallest possible registry to
  reason about.
- You're testing whether the `ComponentProvider` abstraction behaves
  correctly with a non-shadcn provider (it does — that's why this
  package exists).

## What's in it

| Component | Purpose |
|---|---|
| `Box` | A `<div>` with a `className` prop. Foundational. |
| `Stack` | Flex container — `direction`, `gap`, `align`, `justify`. |
| `Container` | Centered max-width wrapper — `size: "sm" \| "md" \| "lg" \| "xl" \| "full"`. |
| `Card` | Bordered, rounded, padded container. |
| `Button` | `<button>` with `variant: "default" \| "ghost" \| "outline"`. |
| `Input` | `<input>` with Tailwind styling. Canvas-safe (auto-readOnly when given a static `value`). |

Plus the reusable velloo helpers borrowed from `@velloo/shadcn-snapshot`:
`Heading`, `Text`, `Icon`, `SVG`, `Image`, `Layer`, `Divider`, `Gradient`,
`Placeholder`.

## What's NOT in it

- `Avatar`, `Tabs`, `Dialog`, `Accordion`, `Select`, `Tooltip` — anything
  that would require either a real component library's machinery or a
  hand-rolled implementation of state + accessibility.
- A theme provider. The provider doesn't bring its own theme — it uses
  the same Tailwind tokens (`--color-background`, `--color-primary`, …)
  the shadcn provider does, so a theme palette generated by Velloo's
  theme MCP works against either provider unchanged.

## How it relates to decisions.md

- See **#22 ComponentProvider abstraction** — this package is the
  intentionally trivial implementation of that interface, used to
  prove the abstraction is real.
- See **#23 Tailwind is a canvas concern** — this provider, like the
  shadcn one, reads Tailwind v4 from the embedded compiler and ships
  its own `@theme` block with the standard token names.
