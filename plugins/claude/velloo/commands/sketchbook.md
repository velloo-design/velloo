Use the velloo-sketchbook skill to start (or continue) a sketchbook: $ARGUMENTS

Work through the velloo MCP tools: they own the design folder; never edit its
files by hand. If the tools aren't available, tell the user to run
`velloo connect` and restart this session. Read `get_sketchbook` first, give the
user the canvas link (`?view=sketchbook`) up front, and let them narrow the
directions and draw the images there.
