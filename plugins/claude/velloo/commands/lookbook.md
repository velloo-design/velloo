Use the velloo-lookbook skill to start (or continue) a lookbook: $ARGUMENTS

Work through the velloo MCP tools: they own the design folder; never edit its
files by hand. If the tools aren't available, tell the user to run
`velloo connect` and restart this session. Read `get_lookbook` first, give the
user the canvas link (`?view=lookbook`) up front, and let them narrow the
directions and draw the images there.
