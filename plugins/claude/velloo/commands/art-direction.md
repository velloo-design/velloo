Use the velloo-art-direction skill to start (or continue) an art direction: $ARGUMENTS

Work through the velloo MCP tools: they own the design folder; never edit its
files by hand. If the tools aren't available, tell the user to run
`velloo connect` and restart this session. Read `get_art_direction` first, give the
user the canvas link (`?view=art-direction`) up front, and let them narrow the
directions and draw the images there.
